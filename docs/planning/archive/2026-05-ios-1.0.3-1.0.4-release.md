## v1.0.3 batch (shipped)

The five-item batch spanned web and iOS. Three of five items shipped in the live
App Store build: items 1, 3 and 4. The owner pivoted from DQ-3 to this batch on
2026-05-08. Cross-AI collaboration remained available through
[`ai-collab.md`](../../../../ai-operating-model/docs/ai-collab.md) and the 3dpa
overlay in [`CLAUDE.md`](../../../CLAUDE.md), but research/review packets were
optional and risk-based rather than a mandatory pilot workflow. Released build
`202605101637` also included remote-printer-catalog hardening,
profile-temperature/nozzle-cap audit fixes and the Advanced filament-temperature
UI fix. Items 2 and 5 remained post-1.0.3 work unless explicitly reopened.
