A device that only updates `last_used_at` can overwrite another device’s field/name edit if it wins `updated_at`; archive-vs-edit can either resurrect a tombstone or discard a valid edit. “Archived rows sync too” is not enough without tombstone precedence/conflict rules. See [spec](/Users/mustafaozturk-macmini/dev/Claude/Projects/3dprintassistant/docs/superpowers/specs/2026-08-20-gear-model-v2-spec.md:158), [spec](/Users/mustafaozturk-macmini/dev/Claude/Projects/3dprintassistant/docs/superpowers/specs/2026-08-20-gear-model-v2-spec.md:245).

Pick one authority and specify mismatch handling. See [spec](/Users/mustafaozturk-macmini/dev/Claude/Projects/3dprintassistant/docs/superpowers/specs/2026-08-20-gear-model-v2-spec.md:101).
